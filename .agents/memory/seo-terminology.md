name: SEO terminology
description: The business's terminology constraint for public website copy and search metadata.
---

Do not use “architect” or “architects” to describe the business or its people in public website copy or search metadata. “Architectural services” is acceptable.

**Why:** The user said those titles may be illegal and misleading for the business.

**How to apply:** Follow this constraint in page copy, metadata, structured data, and future SEO content. Preserve old URLs only when needed for redirects; do not expose the disallowed wording in rendered pages or metadata.

For SEO improvements, preserve the front-facing content. The user permits backend wording changes for Google, including metadata and structured data.

**Why:** The user explicitly allowed backend SEO wording changes as long as the front-facing content remains.

**How to apply:** Keep visible page text and layout unchanged during SEO maintenance unless the user separately requests a visible change.
